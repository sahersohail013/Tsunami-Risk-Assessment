# 🌊 Tsunami Risk Assessment using Machine Learning

This project focuses on **predicting tsunami risk** using historical earthquake and oceanic data. By analyzing geophysical factors such as magnitude, depth, and location, the model classifies whether an event has a potential **tsunami risk (Yes/No)**.  

The project demonstrates an end-to-end **data science pipeline** — from data cleaning and visualization to predictive modeling with **Random Forest Classification**.

---

## 📘 Project Overview

Tsunamis are among the most devastating natural disasters, often triggered by undersea earthquakes.  
This project applies **machine learning** to predict the likelihood of a tsunami based on seismic event parameters.

- **Goal:** Predict whether a given seismic event will generate a tsunami.
- **Type:** Binary Classification
- **Algorithm Used:** Random Forest Classifier
- **Dataset Source:** [Kaggle Earthquake Dataset](https://www.kaggle.com/) *(or your dataset link)*
